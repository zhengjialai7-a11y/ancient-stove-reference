## 初稿依据

- 云端五张母图原始字节的 SHA-256、尺寸与文件字节数已与母图记录一致；没有从珍宝馆重新下载。
- 观察整幅及局部，按原生尺寸换算整数 `x,y,w,h`；逐条查看实际裁切预览并修正贴边、截断、装裱及分类问题。
- 沿用已确认的扩大 B 范围。保留完整可见主体、支撑结构与必要语境；遮挡及原画残损不补画。原画自身截断的部分在命名或证据中说明。
- 使用现有分类表和细分类；不明器具标为待确认。部分组合与聚焦物件视图同时保留，供用户决定保留范围。
- 这是一批初稿，不代表所有资产已穷尽，也不代表用户已接受任何分类偏好。

1. 按草稿 ID 将 baseline 与云端 `artwork_crops` 当前状态及 `artwork_crop_edit_history` 对齐。读取记录时限定这里的五个母图/项目；同标题不作唯一身份依据。

3. 比较删除的初稿、额外增加的框、合并/拆开的组合。不存在的草稿先核实删除历史/用户意图；证据不足标记未知，不能把数据读取失败当作删除。
