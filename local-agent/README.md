# 本机自动采集 v0.8.1 · 3 幅试跑版（验收判定修复）

本版已接通收藏队列、浏览器原图下载、本机上传、云端整文件 SHA-256 核验与逐张关联。需要在你的 Windows 上安装后验证珍宝馆真实下载流程；不能把开发环境测试当作本机下载成功。

## 已安装旧版的更新方法

本次需要更新浏览器插件：先点击队列“暂停”，将新版 `extension` 内全部文件覆盖到原插件目录，保持目录路径，然后在 `edge://extensions` 或 `chrome://extensions` 点击“重新加载”。插件版本应为 **0.8.1**。已安装 0.7.1 本机助手时无需再次安装；下载目录、本机进度、云端收藏都会保留。刷新收藏队列。普通采集沿用原流程；一键验收操作见下方。

v0.8.1 修复了重启保留及中断后复跑核对受 JSON 字段顺序影响的问题。比较时按分段编号核对实际记录；母图 ID、关联项目或失败记录真的发生变化时，仍会显示未通过，并在导出报告中列出差异字段。已有 v0.8.0 验收报告可直接点击“检查重启保留”重新核对，无需重新采集。

v0.8.1 使用网站实际的两步下载流程：“下载”打开“资源文件下载”窗口，再逐行点击“原始高清图像”下的“点击下载”。从原始文件列表自动确认数量、文件编号和原大比例，单图无需填写 1，多图无需手动切换画页。仅在列表核对通过后执行。网页加载、原图列表识别或下载失败会保留作品名、来源、原因、时间和已完成张数，关闭本次自动打开的失败页面并继续下一幅。准备新批次时未失败作品优先，失败作品放到最后。原图下载 3 分钟未启动，或已启动但连续 5 分钟没有进度，也会记录并跳过；正在正常传输的原图继续等待。登录失效、本机助手或上传核验失败会停止整批，保留恢复进度。

本机助手 0.7.1 按每个云端域名读取 Windows 系统代理（含 PAC），或使用已设定的 HTTPS_PROXY 环境变量；启用 Windows 系统受信证书，仍保留 TLS 校验。浏览器专属代理扩展不会自动转换为系统代理。

## 安装（Windows 64 位，Edge / Chrome）

1. 解压整个安装包。把包里的 `extension` 文件夹内容覆盖到原采集助手文件夹，保持原文件夹路径。在 `edge://extensions` 或 `chrome://extensions` 点击采集助手“重新加载”，接受新增“与本机应用通信”权限。没有旧插件时，用“加载解压缩的扩展”选择本包 `extension` 文件夹。
2. 在扩展详情中复制 32 位扩展 ID。双击包里的 `安装本机助手.cmd`，粘贴这个 ID。安装器从 nodejs.org 下载固定版本的便携运行组件，并校验官方 SHA-256；不用先安装 Node、Python，也不要求管理员权限。
3. 打开收藏采集队列并登录图库账号；珍宝馆也保持正常登录。点击“检测本机助手”，再点击“选择下载目录”，选浏览器真正保存原图的目录。

不要删除旧扩展后重新安装，也不要把安装包移走当作卸载方式；这样可能改变扩展 ID。若 ID 改变，重新运行安装器登记新的 ID。安装到当前用户的 `%LOCALAPPDATA%\ArtCapture`。

## 先跑 3 幅

1. 在队列筛选需要的作品，或先选处理批次。点击“准备当前筛选 3 幅”。可只跑 1 幅；先验证单图，再验证多图。
2. 已知作品实际母图总张数可以填写；未知留空，由网站原始文件列表确认。无法确认总张数会记录并跳过当前作品，继续下一幅；不会把下载到一张当作整幅完成。
3. 点击“开始试跑”。插件逐件打开作品页并点击正常下载按钮。插件会打开下载文件列表，再逐张点击原始高清文件的下载按钮；网站要求等待时显示倒计时。
4. 下载完成后，本机助手自动读取该文件、上传原字节、完整回读核验，然后登记母图并关联作品。多图逐张记录；“查看试跑记录”显示每幅进度。

关联依据是完整来源类型＋作品 ID＋当前分段的真实下载链接。不会凭文件名或点击后几分钟的时间窗自动认领其他下载，也不把截图当作原图。

## 本机一键验收

1. 在收藏队列点击“清空批次”，在作品行逐幅“加入本批”，选择 2–3 幅尚未采集的作品，建议包含一幅多图古画。点击“准备当前筛选 3 幅”，确认准备列表。
2. 点击“本机一键验收”中的“一键验收当前准备作品”。本机插件会尝试取消一次已确认来源的本次测试下载，检查失败后另一幅是否继续，再恢复测试取消的作品；多图上传一张后自动暂停、保存并继续；最后复跑已完成作品，通过云端整文件回读核验检查已有分段复用。
3. 页面按实际证据显示“通过、未通过、待验证”。没有多图、下载已经完成而来不及取消、没有失败后续作品等情况，相关项目保持“待验证”。上传、本机助手、账号或核验异常会停止验收并保留原因。
4. 你可以随时点击本机采集区“暂停”；手动暂停后不会自行继续。点击“继续验收”沿用原报告和原批次。普通“开始试跑”与验收不能同时运行。
5. 自动验收结束后，点击“导出验收报告 JSON”留存报告。关闭并完全退出浏览器，再重新打开同一浏览器配置中的队列，点击“检查重启保留”。只有浏览器真实启动事件和保存的作品、分段及失败记录核对一致时，这项才通过。仅刷新网页或重新加载插件不会使其通过。

验收会使用原有下载目录，正常上传并关联测试作品；已有母图按云端核验结果复用。报告保存实际作品、数量、下载/上传/复用证据、测试失败原因和检查点，不保存登录令牌、下载签名地址或完整本机路径。浏览器重启操作单独由你执行，不会自动关闭浏览器。

## 暂停与恢复

- “暂停”保留已经下载的原文件、上传续传地址和逐张记录。继续会复用已经完成的本地下载；已关联分段回读核验后跳过重复下载与上传。
- 下载失败会跳过并记录，继续正常作品；“查看试跑记录”可以看到当前批次和历史失败。新批次不会删除旧失败记录。可点击历史记录旁的“重新准备”再次处理该作品，或使用“重试未完成”重试当前批次。已经完成的分段会核验复用。
- 保持浏览器和电脑开启；网页工作台关闭后，已运行的上传仍可继续。关闭浏览器会停止助手，下一次登录队列后继续。
- 本版只在内存中使用当前云端访问凭据，不把密码或登录令牌写入进度文件。若登录过期，重新登录队列后继续。
- 不删除本地原图，不压缩重编码母图，不自动裁切或发布参考图。

本机进度文件在 `%LOCALAPPDATA%\ArtCapture\state\progress.json`；插件也保存本批次逐张下载记录。不要手动清除这两处记录来“重试”。卸载只取消浏览器与助手的连接，保留原图和进度：双击 `卸载本机助手.cmd`。

## 常见问题

- 找不到本机助手：检查扩展版本是否 v0.7、安装时粘贴的 ID 是否为正在使用的插件 ID，重新运行安装器。
- 原文件不在授权目录：点“选择下载目录”，选择浏览器实际保存的位置。只读取目录内本批次确认的文件，拒绝目录外路径和临时下载文件。
- 未找到总张数：检查“资源文件下载”中的原始高清文件列表是否加载完成；此版本优先使用列表的真实数量。
- 无法识别下载按钮：在已打开的作品页使用原网站下载按钮；仍不识别时，保留错误提示和按钮界面，后续根据实机页面调整适配器。
- 多图文件编号无法确认：记录并跳过当前作品，核对后重试；不会把同一张原图登记成多张母图。
- 本版每批最多 3 幅。单图、多图和恢复流程均在本机验证后，再扩大批次。
