# 本机自动采集 v0.9.2 · 上传成功后清理原图

浏览器插件 v0.9.2，本机助手 v0.7.4。每批最多 3 幅，多图按网站原始高清文件列表逐张处理。下载后上传原字节，整文件回读通过 SHA-256 核验，再关联母图工作台。

## 已安装旧版：保留进度更新

1. 在收藏队列点击“暂停”。
2. 把本包 `extension` 内全部文件覆盖到原插件目录，保持原目录路径。在 `chrome://extensions` 或 `edge://extensions` 点击原插件“重新加载”，确认版本 0.9.2。不要删除原插件或清除存储。
3. 双击本包根目录的 `更新本机助手.cmd`，更新到 0.7.4。这个更新入口直接替换已安装助手的程序文件，保留已登记的扩展 ID、下载目录与 `state/progress.json`；不用重新粘贴 ID。如果提示助手仍在运行，先重新加载插件断开原助手，再运行更新。
4. 刷新收藏队列，展开“助手连接与下载目录”，点击“检测本机助手”，确认助手 0.7.4 和云端连通。
5. 上方“当前任务”显示原批次时，点击“继续采集”或“继续验收”。普通续跑批量核对云端已完成记录后直接处理未完成分段，例如 94/100 从第 95 张继续；中间有缺张则只处理缺失张数。已下载的未完成分段沿用原文件。验收的最后复跑阶段仍重新回读全部母图，并明确显示“验收复查已完成第 X 张”。

这次必须同时更新插件和助手，旧助手不支持本地原图清理。原下载目录、进度与验收报告保留。

## 首次安装

1. 在扩展管理页用“加载解压缩的扩展”选择本包 `extension` 文件夹，复制 32 位扩展 ID。
2. 双击 `安装本机助手.cmd`，粘贴这个 ID。安装到当前用户 `%LOCALAPPDATA%\ArtCapture`，不用预先安装 Node 或 Python。便携 Node 来自固定官方版本，并校验官方 SHA-256。
3. 在收藏队列登录图库账号，珍宝馆保持正常登录。展开“助手连接与下载目录”，检测助手并选择浏览器实际下载目录。

## 日常使用：只看上方当前任务

1. 在作品行“加入本批”，点击“准备所选作品”。没有手动选择时，按当前筛选准备最多 3 幅。原图总张数默认由网站文件列表确认。
2. 新批次模式选择“普通采集”，点击“开始采集”。顶部显示当前作品、已核验并关联的张数、正在处理的分段和具体环节。
3. 下载、上传、回读核验有真实字节信息时显示百分比；等待文件生成或读取云端进度时显示等待时间；重试显示次数和倒计时。
4. 状态显示“已停止，需要继续”时展开“错误详情”查看原因。网络恢复后使用同一处的“继续采集”；点击“暂停”会中断正在等待的云端请求并保存进度。
5. “本批作品”只显示当前 1–3 幅。历史失败、助手设置和验收报告分别折叠，保留原失败历史。历史失败作品可“准备此作品”再处理。
6. 长任务期间保持收藏队列页开启：网页刷新当前账号登录凭据后会同步到本机助手；退出或切换账号会暂停采集。登录凭据仅在内存中传递，刷新不会恢复手动暂停的任务。

## 上传后清理本地原图

展开“助手连接、下载目录与本地清理”：

- 勾选“上传核验并关联成功后，自动删除本地原图”，之后每张新采集母图完成后自动清理。默认关闭，设置按账号保存；暂停或运行期间不能修改。
- 对此前留下的文件，点击“清理已上传原图”。它只读取当前账号的本机助手完成记录，不扫描下载目录。旧文件会先重新回读云端原图核对 SHA-256，再核对本地原图后删除，因此大型合集清理需要时间。
- 删除前确认同一账号、同一作品、同一分段、母图 ID、项目 ID、核验哈希和字节数一致，并确认文件仍在授权下载目录内、没有被替换或修改。
- 删除是直接从磁盘移除，不进入回收站。云端母图、关联和采集进度继续保留；多图每完成一张清理一张，不等待整幅合集结束。
- 上传失败、核验失败、未完成下载、来源或账号不一致的文件保留；文件被占用或无法删除会显示“本地保留待清理”，上传仍算成功。
- 历史清理有独立的数量、阶段和结果提示，可点击上方“暂停”停止；之后重新点击清理会沿用删除记录。保持收藏队列页开启，登录更新会继续同步。
- 已删除的完成分段仍通过云端记录复用，继续采集不会要求重新下载这些本地文件。

## 网络恢复

- 连接重置、超时及临时 HTTP 520/502/503/504 等错误，每个安全请求最多自动重试 3 次，分别等待 2、5、10 秒。耗尽后停止并保留原因与已有进度。
- 回读核验按收到数据后的闲置时间判断：持续接收数据的大图继续核验，不再因整文件传输超过两分钟被中断；连续 60 秒没有收到数据时中断并重试整文件核验。
- 分块上传的响应丢失时，先查询服务端已接收的偏移，再发送剩余字节。不会直接重发可能已经接收的分块。
- 登录、来源歧义、图片哈希不一致等需要人工处理的错误会明确停止。原图下载失败会跳过并留档，优先继续其他作品。
- Windows 系统代理与受信证书继续生效，保留 TLS 校验。浏览器专属代理扩展不会自动成为助手的系统代理；持续连接失败时，检查系统代理和网络后再继续。

## 自动验收

选择 2–3 幅尚未采集的作品，至少包含一幅多图。新批次模式选择“自动验收”，点击“开始一键验收”。验收尝试取消一次已确认来源的测试下载，检查失败后另一幅继续，再恢复测试作品；多图核验一张后自动暂停并恢复；最后复跑已完成作品，对原始字节重新回读和 SHA-256 核验，检查没有重复下载和上传。大型合集的整文件复查仍需时间；日常续跑使用“普通采集”。

结果在折叠的“验收报告与测试操作”中。没有实际执行的检查保持“待验证”。停止后点击上方“继续验收”沿用同一批作品和同一报告。普通“开始采集”不会生成验收报告。只有你明确开始新验收时才创建新报告。

自动验收结束后完全退出并重新打开浏览器，点击“检查重启保留”，再导出报告 JSON。已有报告固定显示原验收批次，与后续普通采集记录分开；重新加载插件或刷新网页不能替代真实浏览器重启。

## 文件与记录

未清理的本机原图保留在授权下载目录；逐张上传与续传记录在 `%LOCALAPPDATA%\ArtCapture\state\progress.json`；浏览器插件保存下载证据、批次和失败历史。不重编码原图；仅开启清理或点击历史清理时删除核验通过的本地原图，不把登录凭据写入记录。

不要通过卸载插件、清空下载目录或删除进度文件来重试。卸载助手只取消浏览器连接，保留原图和进度：使用 `卸载本机助手.cmd`。
