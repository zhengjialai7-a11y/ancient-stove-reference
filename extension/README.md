# 采集助手 v0.8.2：本机自动采集试跑

本机下载、上传和关联的安装与使用步骤见安装包内 `local-agent/README.md`。每批最多3幅，需要本机助手和珍宝馆正常登录。v0.8.2 修复切换普通采集批次后，重启检查把新批次作品写入旧验收报告的问题。已结束报告固定使用原验收终态，读取旧报告时可按原基准恢复其作品列表。保留 v0.8.1 对 JSON 字段顺序误报的修复，可直接重查已有报告，无需重新采集。队列中的“本机一键验收”，可自动检查失败跳过、多图暂停恢复和重复采集，保存并导出报告；浏览器重启保留单独检查。下载失败会记录原因并跳过，继续下一幅；未失败作品优先。失败历史与部分完成的原图会保留，后续可重新准备或重试。本次只更新插件，本机助手 v0.7.1 无需重装。

# 采集助手 v0.5：队列与母图互通

1. 用本包文件覆盖原采集助手文件夹中的同名文件，保留原文件夹路径。
2. 在 Chrome / Edge 扩展管理页点击该扩展的“重新加载”。不要删除原扩展，以免丢失本地历史进度。
3. 打开收藏采集队列：现在会进入与母图工作台同域的云端页面，共用登录。
4. 点击“读取插件已捕获的收藏”，迁移原本地队列及进度。也支持导入旧版导出的 JSON。

云端已导入原718条来源记录，重复导入不会重置已有云端进度。旧版人工“已入库”不作为自动核验凭据；实际母图、字节数、SHA-256、草稿与发布数量从数据库读取。

上传后自动更新状态；同一作品支持多张分段母图。来源 ID 有歧义时先确认关联项目。旧母图可在工作台点击“回读核验当前母图”。任务暂停不删除文件或进度，继续后沿用已有母图。
