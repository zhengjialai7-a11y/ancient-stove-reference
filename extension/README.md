# 采集助手 v0.9.7：问题跳过与集中处理

本次接入 Cloudflare R2：Supabase 继续保存账号、收藏清单、母图元数据和草稿，R2 保存新增母图原文件。已有母图和进度保留。请完整覆盖插件并运行 `更新本机助手.cmd`；母图存储显示“R2 待连接”时，大文件会保留在本地，完成 R2 配置后再继续。开通说明见 [`r2-worker/README.md`](../r2-worker/README.md)。


此次更新补齐：续跑时某幅母图张数冲突不再拦停整批；云端失败及已关联项目的待核对记录也进入问题窗口。默认采集先避开这些记录，审核后从窗口明确准备重试。插件弹窗新增“集中处理问题”直达入口，队列问题行也可直接定位。旧独立母图可定位到原文件，保持母图和草稿身份不变；不支持自动采集的来源保留记录，使用原作/手动上传入口，不猜下载地址。

普通采集可选 20、50、100、200 幅或“全部（当前筛选）”，默认全部，每批上限 5000 幅。按顺序连续处理，下载失败留档跳过；网络断线每 5 分钟自动恢复；重复 ID、重复原图、来源关联、张数与核验错误按作品留档并跳过，继续其他作品。顶部显示整批完成数，本批列表每页 20 幅并跟随当前作品。自动验收保持 1–3 幅小批次。

顶部“集中处理问题”提供待处理、暂缓、已解决和历史记录；支持搜索、分页、查看失败分段、核对云端重复内容、单幅或批量重试、重新下载未完成分段、确认候选项目与处理备注。完成记录仅在重新采集并核验通过后自动解决；暂缓不清除失败历史。新批次自动避开待人工处理的旧失败，可从窗口明确选择重试。

配套本机助手 v0.7.6。展开“助手连接、下载目录与本地清理”，勾选成功后自动删除；旧文件可点击“清理已上传原图”。默认关闭，删除不进入回收站；仅删除助手记录中已经上传、核验和关联成功且本地内容一致的文件，失败或未完成文件保留。

普通续跑批量核对云端完成记录，94/100 直接从第 95 张继续，只处理未完成分段，并恢复本机缺失的关联记录。仅验收的最后复跑阶段重新回读全部原始母图，顶部显示“验收复查已完成第 X 张”。保持收藏队列页开启，当前账号更新后的登录凭据自动同步到本机助手；不会写入文件、切换账号或恢复手动暂停。

网络失败后保存本批任务，每 5 分钟尝试继续未完成分段。顶部显示下次尝试时间、倒计时、“立即重试”和“暂停”；暂停、退出或切换账号取消自动恢复。浏览器重启后按保存计划恢复等待，需同一账号的收藏队列页保持开启。登录失效、重复原图、来源不匹配和哈希核验失败不自动重试。下载网络失败先留档并继续其他作品，之后只重试网络失败作品。保留历史失败记录和上传偏移恢复。新下载原图仍经整文件 SHA-256 回读核验后才登记关联。

已安装旧版：覆盖原 `extension` 目录并重新加载至 0.9.7。助手已是 0.7.6 无需再次更新；更早版本再运行 `更新本机助手.cmd`。无需重新输入扩展 ID，原下载目录与进度保留。首次安装使用 `安装本机助手.cmd`。详细步骤见 `local-agent/README.md`。

# 采集助手 v0.5：队列与母图互通

1. 用本包文件覆盖原采集助手文件夹中的同名文件，保留原文件夹路径。
2. 在 Chrome / Edge 扩展管理页点击该扩展的“重新加载”。不要删除原扩展，以免丢失本地历史进度。
3. 打开收藏采集队列：现在会进入与母图工作台同域的云端页面，共用登录。
4. 点击“读取插件已捕获的收藏”，迁移原本地队列及进度。也支持导入旧版导出的 JSON。

云端已导入原718条来源记录，重复导入不会重置已有云端进度。旧版人工“已入库”不作为自动核验凭据；实际母图、字节数、SHA-256、草稿与发布数量从数据库读取。

上传后自动更新状态；同一作品支持多张分段母图。来源 ID 有歧义时先确认关联项目。旧母图可在工作台点击“回读核验当前母图”。任务暂停不删除文件或进度，继续后沿用已有母图。
