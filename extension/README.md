# 采集助手 v0.9.0：清晰进度与网络恢复

配套本机助手 v0.7.2。顶部当前任务区统一显示作品、已关联张数、下载/上传/回读阶段、重试倒计时和继续按钮；当前批次、历史失败与验收报告分开。云端临时错误最多自动重试 3 次；大图回读按连续无数据判断超时；上传恢复先查询服务端偏移。手动暂停会中断云端请求，已有原图和进度保留。

已安装旧版：覆盖原 `extension` 目录并重新加载插件，然后双击 `更新本机助手.cmd`。无需重新输入扩展 ID，原下载目录与进度保留。首次安装使用 `安装本机助手.cmd`。详细步骤见 `local-agent/README.md`。

# 采集助手 v0.5：队列与母图互通

1. 用本包文件覆盖原采集助手文件夹中的同名文件，保留原文件夹路径。
2. 在 Chrome / Edge 扩展管理页点击该扩展的“重新加载”。不要删除原扩展，以免丢失本地历史进度。
3. 打开收藏采集队列：现在会进入与母图工作台同域的云端页面，共用登录。
4. 点击“读取插件已捕获的收藏”，迁移原本地队列及进度。也支持导入旧版导出的 JSON。

云端已导入原718条来源记录，重复导入不会重置已有云端进度。旧版人工“已入库”不作为自动核验凭据；实际母图、字节数、SHA-256、草稿与发布数量从数据库读取。

上传后自动更新状态；同一作品支持多张分段母图。来源 ID 有歧义时先确认关联项目。旧母图可在工作台点击“回读核验当前母图”。任务暂停不删除文件或进度，继续后沿用已有母图。
